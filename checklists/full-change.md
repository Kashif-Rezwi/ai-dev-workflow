# Full-Change Checklist

For features, architecture, and irreversible changes (full gear).

- [ ] Read applicable instructions; checked branch, commit, and working tree
- [ ] Active spec uses the repo's planning location: goal, non-goals, observable acceptance criteria, constraints
- [ ] Meaningful alternatives and decisions recorded where needed; existing approvals carried forward
- [ ] Ordered tasks name affected files, behavior, and verification; material scope decisions resolved
- [ ] Implementation proceeds in manageable steps; spec reflects material findings
- [ ] Existing architecture docs updated if system shape changed; separate ADR only if a durable decision needs it
- [ ] Completed the shared review in `checklists/pre-merge-review.md`
- [ ] If work remains, updated the spec's checkpoint using `references/workflow.md`
